# Admin 登录页 PRD

## 概述
管理后台登录入口，仅允许已授权管理员账号登录。

## 用户场景
- 管理员通过账号密码登录后台
- 不支持第三方登录与注册（后台账号由超管预创建）

## 页面结构

### 居中卡片
- **账号**输入框（必填）
- **密码**输入框（必填）
- **记住我**复选框
- 「登录」主按钮
- 「忘记密码」链接（点击发邮件给超管）

## 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `account` | string | 管理员账号 |
| `password` | string | 密码 |
| `remember` | boolean | 7 天免登录 |

## 接口
- `POST /api/admin/auth/login` 管理员登录
- `POST /api/admin/auth/logout` 退出

## 状态
- 默认值：占位展示，仅说明用途，尚未对接接口。
